# SWYNEX Exploratory Data Analysis

## Task 2: Exploratory Data Analysis (EDA)

This project was completed as part of my Data Analytics Internship at SWYNEX Technologies.

## Dataset
Titanic passenger dataset used for Exploratory Data Analysis.

## Tools Used
- Microsoft Excel
- PivotTables
- Excel formulas
- Charts

## EDA Performed
- Calculated key statistics
- Analyzed survival by gender
- Analyzed survival by passenger class
- Analyzed passengers by embarkation port
- Analyzed passengers by age group
- Analyzed average fare by passenger class
- Identified key trends and patterns

## Key Statistics
- Total Passengers: 891
- Total Survivors: 342
- Survival Rate: 38.38%
- Average Age: 29.39
- Average Fare: 32.20

## Key Insights
1. The overall survival rate was approximately 38.38%, with 342 out of 891 passengers surviving.
2. Female passengers had 233 survivors, compared with 109 male survivors.
3. First-class passengers had the highest average fare among all passenger classes.
4. Most passengers were adults, with 565 passengers in the Adult age group.
5. Southampton (S) was the most common embarkation port among the passengers.
